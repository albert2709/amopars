# XPath Lead Logger (Chrome Extension)

Расширение по кнопке выполняет XPath-запрос:

```xpath
//div[@class="pipeline_leads__field h-text-overflow"]
```

Далее:
1. Берёт только значения, где есть **ровно 11 цифр**.
2. Добавляет каждое найденное значение в лог в формате: `дата время | номер`.
3. Обновляет текстовый файл `xpath_results_log.txt` (скачивается автоматически).

## Установка

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Load unpacked / Загрузить распакованное**.
4. Выберите папку с этим проектом.

## Использование

1. Откройте нужную страницу сайта.
2. Нажмите на иконку расширения.
3. Нажмите кнопку **«Собрать по XPath и записать»**.

Если найдены значения с 11 цифрами, они будут добавлены в лог и сохранены в `xpath_results_log.txt`.
